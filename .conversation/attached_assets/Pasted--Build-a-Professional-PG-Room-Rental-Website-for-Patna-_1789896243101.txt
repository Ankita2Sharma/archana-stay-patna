# Build a Professional PG & Room Rental Website for Patna, Bihar

## ROLE

Act as a senior full-stack developer, UI/UX designer, database architect, SEO specialist, and product designer.

Build a complete, production-ready **PG and room rental marketplace website** inspired by the functionality and user experience of modern PG/property listing websites such as PGChoice.

IMPORTANT:

* Do NOT copy PGChoice's logo, branding, text, images, source code, or copyrighted design.
* Use it only as inspiration for the general property-listing experience.
* Create an original, modern, trustworthy design.
* The website must work on desktop, tablet, and mobile.
* Do not create only a static UI/mockup.
* Build the actual functional application with frontend, backend, database, authentication, admin panel, search, filters, enquiry functionality, WhatsApp integration, and Google Maps.
* Use clean, maintainable, production-quality code.

---

# 1. WEBSITE PURPOSE

Create a website where users can:

1. Search for PGs and rooms in Patna.
2. Browse available properties.
3. Filter properties according to their requirements.
4. View detailed property information.
5. See room types, pricing, amenities, photos, location, and availability.
6. Contact the property owner through:

   * WhatsApp
   * Phone
   * Enquiry form
7. View the property location on Google Maps.
8. Submit an enquiry.
9. Save/favorite properties.
10. Browse the website comfortably from a mobile phone.

The website should initially focus on:

**Patna, Bihar, India**

but the architecture should allow adding other cities later.
