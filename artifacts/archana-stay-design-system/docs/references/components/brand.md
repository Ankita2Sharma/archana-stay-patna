## Extracted behavior and styling

The brand is a compact inline mark paired with the “Archana Stay” wordmark and
the uppercase strapline “A place to settle in.” The mark uses a navy diamond
outline with a gold lower edge and a small gold center accent. The wordmark uses
Fraunces while the strapline uses small, widely tracked DM Sans.

There is no standalone logo image in the source app. Consumers should preserve
the CSS mark or provide an approved brand asset rather than using the unrelated
generated favicon.
